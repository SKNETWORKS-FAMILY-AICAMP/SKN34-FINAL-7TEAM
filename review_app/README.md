# CAIFE 질문 검토실

기존 합성 질문과 예상 행동을 살펴보고 사람이 평가하는 별도의 Streamlit 앱입니다.

## 실행

프로젝트 루트에서 실행합니다.

```powershell
docker compose -f compose.review.yaml up -d --build
```

브라우저에서 http://127.0.0.1:8501 을 엽니다. 종료할 때는 `docker compose -f compose.review.yaml stop`을 사용합니다.

## 데이터와 검토

- 로컬 전처리 데이터에서 단일 의도 576건과 중복을 제외한 대화 시나리오 96건을 읽습니다. 원본이 없다면 누락된 파일이 표시됩니다.
- 원본은 읽기 전용이며 질문 수정, 예상 행동과 안내 문구, 최종 평가 및 이력은 Docker 볼륨의 SQLite에 저장합니다. 컨테이너를 재시작해도 볼륨은 유지됩니다.
- 승인된 학습용 질문만 JSONL로 내려받을 수 있습니다. 검증·시험·보류 데이터는 내보내지 않습니다. 평가용 질문을 열람하거나 수정하면 최종 평가의 독립성에 영향을 줄 수 있습니다.
- 질문·행동 생성 AI와 총괄 검토 AI는 연결 전입니다. 자동 생성이나 정기 실행도 아직 동작하지 않습니다.

## 기존 데이터 점검

- 단일 의도 문장 576건에는 의도 라벨이 있으나 예상 행동과 답변은 없습니다.
- 대화 시나리오 96건 중 64건에 예상 행동이 있습니다. 나머지 32건의 행동과 전체 예상 답변은 작성되지 않았습니다.
- 메뉴 정규화 데이터는 203건이며, 주문 옵션과 샷 정보는 구조화 데이터에 비어 있습니다. 카페인 결측 38건, 알레르기 결측 69건입니다. 값이 없다는 뜻으로 해석하지 않습니다.
- 55개 메뉴 별칭은 여러 메뉴에 대응하므로 주문 시 구분이 필요합니다.
- 주문 의도 분류 모델 학습과 STT, LLM 주문 처리는 아직 구현되지 않았습니다.

## 보관

데이터 볼륨을 삭제하면 검토 결과와 이력도 삭제됩니다. `docker compose ... down -v`는 사용하지 마세요.
